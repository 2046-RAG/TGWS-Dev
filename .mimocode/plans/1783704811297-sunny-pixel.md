## P1: Hero视频动效+Key Message不吸睛

### 核实方法
- Playwright截图: hero.png (1440x900)
- 读取: `HeroSection.tsx` — 当前视频URL、文案、动效

### 初步发现
- 当前视频: CloudFront CDN托管的复古GoldStar电脑视频
- Key Message: "Build. Run. Protect., Your End-to-End IT Partner"
- 动效: 鼠标scrubbing(左右移动控制播放进度) + 渐变遮罩

### 根因分析
- 视频内容(复古电脑)与AI/IT主题不匹配 — 用户在S46已指出
- Key Message过于通用，缺乏冲击力
- 缺少动态文字效果(打字机/渐入)

### 修复方案
1. **视频替换**: 从已下载的30个AI/IT视频中选择更匹配的素材
2. **Key Message重写**: 更具冲击力的Slogan
3. **文字动效**: 添加渐入/打字机效果
4. **不动**: 渐变遮罩、scrubbing交互保留

### 影响范围
- `HeroSection.tsx` (修改)
- `en.json` / `zh.json` (文案更新)
- 不影响其他页面

2. **视觉重设计**: 调用impeccable技能评估并重设计
3. **微交互**: 添加hover效果、点击展开
4. **不动**: 三支柱架构本身保留

### 影响范围
- `home/page.tsx` (Storyline部分修改)
- `en.json` / `zh.json` (文案更新)
- 不影响其他页面

## P3: 合作伙伴Logo墙重叠/大小不一/无滚动

### 核实方法
- Playwright截图: Footer/首页Logo区域
- 读取: Logo展示组件(Footer.tsx或首页)

### 初步发现
- 19个Logo图片已加载
- 无CSS滚动动画
- 布局可能使用flex但缺少统一尺寸约束

### 根因分析
- 缺少`object-fit: contain`或固定尺寸
- 无marquee/scroll动画CSS
- Logo原始尺寸不一致

### 修复方案
1. **统一尺寸**: 所有Logo设为固定宽高(如80x40px) + `object-fit: contain`
2. **无限滚动**: CSS marquee动画或JS滚动
3. **响应式**: 移动端单行滚动，桌面端多行
4. **不动**: Logo图片文件本身不变

### 影响范围
- Logo展示组件 (修改CSS)
- `globals.css` (添加marquee动画)
- 不影响其他页面

## P7: 暗色模式完全不工作

### 核实方法
- 读取: `globals.css` — dark:规则
- 读取: 多个组件 — dark:变体
- Playwright截图: dark-hero.png, dark-products.png

- globals.css中**0条dark:规则**

### 修复方案
1. **globals.css**: 添加dark mode主题变量
2. **所有页面组件**: 添加dark:前缀
3. **关键组件**: Navbar/Footer/Card/Form/BlogDetail/CaseStudyDetail
4. **保持**: DarkModeToggle逻辑不变
5. **不动**: 页面结构、路由

### 影响范围
- `globals.css` (添加dark规则)
- 所有页面组件 (添加dark:变体)
- 不影响页面结构、路由、数据
