# TicketForm 功能改造计划

## 目标

将TicketForm从4字段基础表单改造为7字段完整工单表单，支持产品下拉、问题发生时间、800字限制、粘贴截图、任意格式附件(50MB)。

## 改造清单

### 1. Product字段：自由文本 → 产品下拉选择

**文件**: `src/components/tickets/TicketForm.tsx`

- 新增 `products` state，组件挂载时从 `/api/products` 获取产品列表
- Product字段改为 `<select>` 下拉框，选项来自Sanity产品数据
- 保留一个 "Other (specify below)" 选项，选中后显示自由输入框
- 选项按 category 分组显示: Build / Run / Protect

**新增文件**: `src/app/api/products/route.ts`
- GET接口，查询Sanity: `*[_type == "product"] | order(category asc, order asc) { _id, title, category }`
- 返回产品列表供前端使用

### 2. 问题发生时间（精确到分钟）

**文件**: `src/components/tickets/TicketForm.tsx`

- 新增 `occurredAt` state，类型 `string`，格式 `YYYY-MM-DDTHH:mm`
- 新增 `<input type="datetime-local">` 字段
- 默认值: 当前时间 `new Date().toISOString().slice(0, 16)`
- 验证: 不允许选择未来时间

**文件**: `src/app/api/tickets/route.ts`
- POST body 新增 `occurredAt` 字段
- 插入数据库时写入 `occurred_at` 列

**文件**: `supabase/migrations/002_add_occurred_at.sql` (新增)
- `ALTER TABLE tickets ADD COLUMN occurred_at TIMESTAMP;`

### 3. Description 800字限制 + 字数统计

**文件**: `src/components/tickets/TicketForm.tsx`

- textarea 添加 `maxLength={800}`
- 新增 `charCount` 计算: `formData.description.length`
- 右下角显示字数统计: `{charCount}/800`
- 接近限制时(>750)统计变橙色，达到限制(=800)变红色

### 4. 粘贴截图支持

**文件**: `src/components/tickets/TicketForm.tsx`

- 新增 `pastedImages` state: `Array<{ file: File; preview: string }>`
- 新增粘贴区域 `<div onPaste={handlePaste}>`:
  - 虚线边框 + 提示 "Paste screenshot here (Ctrl+V)"
  - 也支持点击触发文件选择器
- `handlePaste` 逻辑:
  - 从 `clipboardData.items` 中筛选 `image/*` 类型
  - 创建 `File` 对象 + `URL.createObjectURL` 生成预览
  - 添加到 `pastedImages` 数组
- 每张粘贴图显示缩略图 + 删除按钮(X)
- 提交时将粘贴图片合并到附件列表一起上传

### 5. 附件格式放开

**文件**: `src/components/tickets/TicketForm.tsx`
- 移除 `<input>` 的 `accept` 属性（允许任意格式）

**文件**: `src/app/api/upload/route.ts`
- 移除 `ALLOWED_TYPES` 白名单检查
- 保留 `MAX_SIZE` 大小限制
- 只验证文件是否存在和大小

### 6. 附件大小限制 10MB → 50MB

**文件**: `src/app/api/upload/route.ts`
- `MAX_SIZE` 从 `10 * 1024 * 1024` 改为 `50 * 1024 * 1024`

**文件**: `src/components/tickets/TicketForm.tsx`
- 提示文案更新: "Max 50MB per file"

### 7. i18n 新增键

**文件**: `src/messages/en.json` 和 `src/messages/zh.json`

新增键:
```json
{
  "occurredAt": "Problem Occurrence Time",
  "occurredAtPlaceholder": "When did the problem occur?",
  "pasteScreenshot": "Paste screenshot here (Ctrl+V)",
  "orClickToUpload": "or click to upload",
  "charCount": "{count}/800",
  "otherSpecify": "Other (please specify)",
  "maxFileSize": "Max 50MB per file. Any format accepted."
}
```

## 实施顺序

1. 数据库migration (加occurred_at字段)
2. 新增 `/api/products` 路由
3. 修改 `/api/upload` (移除格式限制, 改50MB)
4. 修改 `/api/tickets` POST (加occurredAt)
5. 改造 TicketForm 组件 (7项功能)
6. 更新 i18n JSON (en + zh)
7. 本地验证 (npm run dev → 手动测试每个字段)

## 验证方式

1. `npm run lint` — 0 errors
2. `npx tsc --noEmit` — 0 errors
3. `npm run build` — 构建成功
4. 手动测试:
   - 访问 /en/support → 登录 → New Ticket
   - 验证Product下拉显示Sanity产品列表
   - 验证时间选择器精确到分钟
   - 验证Description输入800字后截断
   - 验证Ctrl+V粘贴截图显示预览
   - 验证上传zip文件成功(无格式限制)
   - 验证50MB以上文件被拒绝
5. 运行现有Vitest测试确保无回归
