# Global Search 生产级实现设计方案 v2

> 最后更新: 2026-01-25

## [S1] 项目概述

### 1.1 目标
为TechGuru网站实现一个生产级就绪的Global Search功能，支持多模态搜索（文字+图片）、站内站外融合、AI智能整合，以及商业闭环（能力缺口检测+线索转化）。

### 1.2 核心价值
- **专业性**: 每个搜索结果体现TechGuru的专业能力
- **行动导向**: 不只是信息，而是下一步行动建议
- **差异化**: AI整合+公司专长，与普通搜索引擎区别
- **商业闭环**: 检测能力缺口，自动转化为销售线索

## [S2] 功能需求

### 2.1 多模态搜索

#### 输入方式（全部支持）

| 输入方式 | 用户操作 | 实现技术 | 触发条件 |
|----------|----------|----------|----------|
| 文字输入 | 键盘输入 | Input事件 | 实时搜索 |
| 文件上传 | 点击📷按钮 | `<input type="file">` | 点击按钮 |
| 粘贴图片 | Ctrl+V | Clipboard API | paste事件 |
| 拖拽上传 | 拖拽到搜索框 | dragover/drop | 拖拽操作 |
| 图片链接 | 粘贴URL | 正则匹配HTTP/HTTPS | 粘贴时检测 |

#### 图片限制

| 限制项 | 值 | 说明 |
|--------|-----|------|
| 文件大小上限 | 5MB | 覆盖99%使用场景 |
| 支持格式 | JPG, PNG, WebP, GIF | 常见图片格式 |
| 超限处理 | 前端压缩 | >2MB自动压缩 |

#### 多模态处理（三级降级）

| 优先级 | 方案 | 免费额度 | 说明 |
|--------|------|----------|------|
| 1 | Google Gemini API | 15K RPD | 图片理解+文字提取 |
| 2 | Google Cloud Vision | 1000次/月 | 纯OCR文字提取 |
| 3 | Tesseract.js | 无限 | 纯前端OCR（降级） |

### 2.2 搜索范围

| 内容类型 | 数据源 | 搜索方式 | 需要登录 |
|----------|--------|----------|----------|
| 产品 | Sanity CMS | GROQ查询 | ❌ |
| 方案 | Sanity CMS | GROQ查询 | ❌ |
| 博客 | Sanity CMS | GROQ查询 | ❌ |
| FAQ | Sanity CMS | GROQ查询 | ❌ |
| 站外资源 | Google CSE + Tavily API | 外部API | ❌ |
| 工单 | Supabase | SQL查询 | ✅ 仅自己的工单 |

### 2.3 结果展示方式（站内优先分组）

```
搜索结果
    │
    ├─── 🤖 AI摘要（Tavily生成）
    │
    ├─── 🏠 站内结果（TechGuru能力）
    │    • 产品
    │    • 方案
    │    • 博客
    │    • FAQ
    │
    └─── 🌐 站外结果（行业资源）
         • Google结果
         • Tavily结果
```

### 2.4 AI智能整合

每个搜索结果经过AI整合，融合：
- 站内产品/方案/最佳实践
- 站外行业洞察/竞品信息
- TechGuru专业视角

### 2.5 自定义过滤条件

| 过滤维度 | 选项 | 说明 |
|----------|------|------|
| 内容类型 | 产品/方案/博客/FAQ | 按内容分类过滤 |
| 产品支柱 | Build/Run/Protect | 按产品线过滤 |
| 行业 | 医疗/金融/零售/物流/教育/政府 | 按目标行业过滤 |

### 2.6 能力缺口检测与商业闭环

| 步骤 | 触发条件 | 执行动作 |
|------|----------|----------|
| 1 | 搜索词匹配不到站内产品/方案 | 检测能力缺口 |
| 2 | 确认是公司当前短板 | 生成事件报告 |
| 3 | 事件确认 | 发送邮件给管理层+销售+技术 |
| 4 | 页面展示 | 显示致歉+邀请留联系方式 |
| 5 | 用户提交表单 | 创建销售线索 |
| 6 | 跟进 | 48小时内联系客户 |

### 3.2 API设计

#### 搜索API

```
POST /api/search
```

**请求体**:
```json
{
  "query": "超融合",
  "type": "text",
  "imageData": "base64...",
  "filters": {
    "contentType": ["product", "solution"],
    "pillar": ["run"],
    "industry": ["finance"]
  },
  "locale": "en"
}
```

**响应体**:
```json
{
  "success": true,
  "data": {
    "aiSummary": "AI生成的综合摘要...",
    "internalResults": [...],
    "externalResults": [...],
    "capabilityGap": {
      "detected": false,
      "gapDescription": null,
      "notificationSent": false
    }
  }
}
```

#### 线索提交API

```
POST /api/search/lead
```

**请求体**:
```json
{
  "name": "张三",
  "email": "zhang@example.com",
  "phone": "+63 912 345 6789",
  "company": "ABC Corp",
  "searchQuery": "SASE零信任方案",
  "gapDescription": "用户搜索SASE零信任方案"
}
```

### 3.3 数据模型

#### 销售线索（Supabase）

```sql
CREATE TABLE leads (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT,
  email TEXT,
  phone TEXT,
  company TEXT,
  search_query TEXT NOT NULL,
  gap_description TEXT,
  source TEXT DEFAULT 'global_search',
  status TEXT DEFAULT 'new',
  assigned_to UUID REFERENCES users(id),
  notes TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 搜索日志（Supabase）

```sql
CREATE TABLE search_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID,
  query TEXT NOT NULL,
  query_type TEXT DEFAULT 'text',
  filters JSONB,
  results_count INTEGER,
  capability_gap_detected BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
