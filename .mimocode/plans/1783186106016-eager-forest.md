# TGWS 大模型接入方案

## 项目背景
TGWS是一个B2B IT服务公司网站，目标用户是IT经理/CTO，提供Build/Run/Protect三大服务。

---

## 一、大模型应用场景脑洞

### 场景1：智能工单助手（P0 - 最高价值）

**功能描述**：
- 工单自动分类：根据描述自动判断类别（Build/Run/Protect）
- 智能优先级：分析紧急程度，自动设置优先级
- 解决方案推荐：基于历史工单推荐解决方案
- 回复草稿生成：为客服人员生成回复建议

**用户价值**：IT经理提交工单时，AI助手可以：
```
用户输入："我们的防火墙突然无法连接，所有业务中断"
AI分析：
- 类别：Protect（网络安全）
- 优先级：Critical（业务中断）
- 推荐产品：Fortinet NGFW
- 建议回复："我们已收到紧急工单，正在为您安排工程师..."
```

**技术实现**：
```typescript
// src/lib/ai/ticket-analyzer.ts
export async function analyzeTicket(description: string) {
  const response = await fetch('https://api.deepseek.com/v1/chat/completions', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${process.env.DEEPSEEK_API_KEY}` },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [{
        role: 'system',
        content: `你是TechGuru的工单分析助手。分析工单内容，返回JSON：
        {
          "category": "build|run|protect",
          "priority": "low|medium|high|critical",
          "suggestedProducts": ["产品列表"],
          "replyDraft": "建议回复"
        }`
      }, {
        role: 'user',
        content: description
      }]
    })
  });
  return response.json();
}
```

## 二、大模型选型建议

### 推荐方案：GPT-4o-mini（首选）

**用户场景**：英文为主的B2B企业客户（IT经理/CTO在香港/东南亚）

| 维度 | 评分 | 说明 |
|------|------|------|
| **英文能力** | ⭐⭐⭐⭐⭐ | 原生英文，专业术语理解优秀 |
| **成本** | ⭐⭐⭐⭐⭐ | $0.15/百万input，$0.6/百万output，极低成本 |
| **性能** | ⭐⭐⭐⭐ | GPT-4o-mini性能优秀，响应快速 |
| **API易用性** | ⭐⭐⭐⭐⭐ | OpenAI原生API，文档完善 |
| **响应速度** | ⭐⭐⭐⭐⭐ | 平均1-2秒响应 |
| **生态集成** | ⭐⭐⭐⭐⭐ | 丰富的SDK和工具 |

**API接入示例**：
```typescript
const OPENAI_API_KEY = process.env.OPENAI_API_KEY;

async function callOpenAI(messages: Array<{role: string; content: string}>) {
  const response = await fetch('https://api.openai.com/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${OPENAI_API_KEY}`
    },
    body: JSON.stringify({
      model: 'gpt-4o-mini',
      messages,
      temperature: 0.7,
      max_tokens: 1000
    })
  });
  return response.json();
}
```
