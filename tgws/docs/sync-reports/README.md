# Doc-Sync 差异报告

## 目录说明
本目录存放TGWS项目文档同步检查的差异报告。

## 文件命名规范
- 格式: `YYYY-MM-DD-<检查类型>.md`
- 示例: `2026-07-14-full-check.md`

## 报告内容
每次检查生成的报告应包含:
1. 检查时间
2. 检查范围
3. 发现的差异
4. 修复建议
5. 修复状态
