# TGWS 大模型集成总体规划

## 项目概述

**目标**：为TechGuru B2B IT服务网站集成AI能力，提升用户体验和运营效率。

**用户场景**：英文为主的IT经理/CTO（香港/东南亚）

**技术栈**：
- 前端：Next.js 16 + React 19
- 后端：Supabase + Sanity
- AI：OpenAI GPT-4o-mini
- 部署：Vercel

## 场景1：智能工单助手

### 功能概述
AI自动分析工单内容，提供分类、优先级、解决方案推荐和回复草稿。

### 核心价值
- 工单处理时间减少50%
- 分类准确率提升至95%
- 客服回复效率提升3倍

### 用户流程
```
用户提交工单 → AI实时分析 → 显示建议 → 用户确认/修改 → 提交
```

### 技术实现
- **API端点**：`/api/ai/analyze-ticket`
- **模型**：GPT-4o-mini
- **防抖**：500ms延迟避免频繁调用
- **降级**：AI不可用时使用规则引擎

### 成本估算
- 调用量：50次/天
- Token消耗：~500 token/次
- 月度成本：$0.32

## 场景2：智能产品推荐

### 功能概述
理解用户技术需求，从21个产品中推荐最合适的产品，生成迁移方案。

### 核心价值
- 产品推荐精准度提升30%
- VMware迁移转化率提升25%
- 用户决策时间缩短40%

### 用户流程
```
用户描述需求 → AI分析需求 → 匹配产品 → 生成方案 → 展示推荐
```

### 技术实现
- **API端点**：`/api/ai/recommend`
- **产品知识库**：Sanity产品schema + 特性标签
- **预筛选**：先用规则过滤到8个候选，再用AI精选
- **会话持久化**：Supabase存储推荐历史

### 成本估算
- 调用量：20次/天
- Token消耗：~800 token/次
- 月度成本：$0.15

## 场景3：内容生成助手

### 功能概述
自动生成博客摘要、翻译内容、SEO建议和社交媒体文案。

### 核心价值
- 内容产出效率提升5倍
- 翻译成本降低90%
- SEO优化自动化

### 用户流程
```
编辑输入内容 → 选择生成类型 → AI生成 → 编辑审核 → 发布
```

### 技术实现

- **生成类型**：摘要、翻译、SEO、社交媒体

### 成本估算
- 调用量：10篇/天
- Token消耗：~2000 token/篇
- 月度成本：$0.08

## 场景4：智能搜索

### 功能概述
语义搜索 + 智能问答，理解自然语言查询并从知识库中找到答案。

### 核心价值
- 搜索准确率提升60%
- 用户找到信息时间缩短70%
- 支持复杂技术问题问答

### 用户流程
```
用户输入查询 → 语义理解 → 检索相关文档 → 生成答案 → 展示来源
```

### 技术实现
- **搜索索引**：pgvector向量存储 + FTS全文索引
- **嵌入模型**：text-embedding-3-small
- **RAG管道**：检索 → 上下文注入 → GPT-4o-mini生成
- **流式响应**：Server-Sent Events实时返回

### 成本估算
- 调用量：100次/天
- Token消耗：~300 token/次
- 月度成本：$0.12

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| API调用失败 | 功能不可用 | 降级到规则引擎，不影响核心功能 |
| 响应延迟 | 用户体验差 | 设置超时（5秒），显示加载状态 |
| 成本超支 | 预算超支 | 设置月度预算上限（$10） |
| 数据隐私 | 合规风险 | 不发送敏感信息，只发送必要内容 |
| 内容质量 | 品牌风险 | AI生成内容需人工审核后发布 |
| 幻觉输出 | 误导用户 | 添加来源引用，提供"不确定"选项 |

---

## 安全考虑

1. **API密钥管理**：使用环境变量，不硬编码
2. **数据脱敏**：发送给AI前移除PII（邮箱、电话、IP）
3. **速率限制**：每个用户30次/小时
4. **内容审核**：AI生成内容标记为草稿
5. **日志记录**：记录所有AI调用用于审计
6. **成本监控**：实时监控API使用量
